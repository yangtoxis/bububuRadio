# БУБУБУ РАДИО

Discord-бот для непрерывного lofi-радио: несколько станций, реальное
название трека прямо с потока, кнопки перехода в Spotify/YouTube/Яндекс.Музыку,
управление только для DJ-роли, слип-таймер, режим 24/7 и таблица лидеров по
времени прослушивания.

Обычное музыкальное воспроизведение (YouTube/Spotify-поиск, очередь треков,
`/skip`, `/queue`) в проекте отсутствует по дизайну — это радио, а не
музыкальный бот.

## Возможности

- **4 радиостанции** (`src/config/stations.yaml`), переключаются через
  `/radio` — владелец-only список, пользователи не могут добавлять свои.
- **Реальное название трека.** Отдельное подключение читает ICY-метаданные
  потока (`src/sources/IcyMetadataReader.js`) — при смене трека старое
  публичное сообщение удаляется, новое показывает название и кнопки поиска
  трека на Spotify / YouTube / Яндекс.Музыке (с настоящими логотипами
  сервисов, залитыми как emoji приложения).
- **Приватная панель управления.** Полный плеер (пауза/стоп/громкость/смена
  станции/выход) показывается только тому, кто вызвал команду (ephemeral) —
  остальным в канале он не нужен, раз управлять могут не все.
- **DJ-роль.** `/dj-role @Роль` ограничивает управление радио одной ролью;
  пока роль не назначена — доступно всем. Участники с правом Manage Server
  всегда могут управлять, независимо от роли.
- **Слип-таймер и 24/7.** `/sleep <минуты>` — бот сам выйдет из канала;
  `/247` — не выходить из опустевшего канала (настройка хранится в БД,
  переживает перезапуск).
- **Таблица лидеров.** Каждую минуту реального прослушивания (станция
  играет, не на паузе) всем в канале засчитывается время; `/leaderboard`
  показывает топ-10 по серверу.
- **DAVE (E2EE).** С 2 марта 2026 Discord требует поддержку сквозного
  шифрования голоса — без неё голосовое соединение сразу рвётся кодом
  `4017`. Бот использует `@discordjs/voice` версии, поддерживающей DAVE
  (тянет `@snazzah/davey`), — см. раздел «Диагностика» ниже.
- **Устойчивость.** Автопереподключение при обрыве потока (реконнект на
  уровне ffmpeg + полный перезапуск процесса с backoff при жёстком падении),
  подробный debug-лог голосового соединения (`LOG_LEVEL=debug`).
- **Изоляция серверов.** `AudioManager` → `Map<guildId, AudioSession>` —
  разные Discord-серверы полностью независимы (своя станция, громкость,
  пауза, DJ-роль, статистика).

## Команды

| Команда | Кто может | Что делает |
|---|---|---|
| `/play` | DJ | Зайти в канал и включить радио (или снять с паузы) |
| `/stop` | DJ | Пауза — бот остаётся в канале |
| `/leave` | DJ | Полностью выйти из канала |
| `/radio` | DJ | Открыть выбор станции |
| `/volume <0-100>` | DJ | Громкость |
| `/sleep <минуты>` | DJ | Выйти из канала через N минут (`0` — отменить) |
| `/247` | DJ | Переключить режим 24/7 |
| `/dj-role [@роль]` | Manage Server | Назначить/снять DJ-роль |
| `/leaderboard` | Все | Топ-10 слушателей на сервере |

## ⚠️ Ограничение платформы Discord

Один бот-токен может иметь только **одно** голосовое подключение на **один
сервер** одновременно — это ограничение самого Discord, а не этого кода.
Изоляция в этом проекте реализована между **разными серверами**; две
параллельные сессии внутри одного сервера потребовали бы отдельных ботов
(отдельных токенов).

## Диагностика: голос подключается, но не играет

Если бот заходит в канал, но звука нет, а в логе (`LOG_LEVEL=debug`) видно,
что `Voice connection state change` крутится между `signalling` и
`connecting`, не доходя до `ready` — включите отладку voice-протокола (она
уже подписана в `AudioSession`, ищите строки `[voice] [NW] ...`) и смотрите
на `[WS] closed with code`:

- **`4017` (E2EE/DAVE protocol required)** — сервер требует протокол DAVE, а
  установленная версия `@discordjs/voice` его не поддерживает. Решение:
  `@discordjs/voice` должен быть `^0.19.x` или новее (тянет
  `@snazzah/davey` автоматически как обычную зависимость) — `npm install`
  и пересборка. Это самая частая причина с марта 2026.
- **Зависает на `connecting`, WS вообще не закрывается** — похоже на
  сетевую проблему (VPN/DPI режет UDP до `*.discord.media`, или битый IPv6
  на хосте). Код уже форсирует `dns.setDefaultResultOrder('ipv4first')`
  (`src/index.js`) на случай нерабочего IPv6; если это не помогает — дело в
  самой сети (VPN/провайдер), нужен другой хост или отключение VPN на
  машине с ботом.

## Стек

- **discord.js v14** — Discord API
- **@discordjs/voice ^0.19** + **@snazzah/davey** — голосовые подключения с
  поддержкой DAVE (E2EE)
- **ffmpeg** (`ffmpeg-static`) — декодирование HTTP/HTTPS радиопотоков с
  автопереподключением (`-reconnect` флаги)
- **better-sqlite3** — настройки сервера и статистика прослушивания
  (не активное состояние воспроизведения — оно всегда только в памяти)
- **js-yaml** — загрузка списка станций из `stations.yaml`

## Быстрый старт (Docker)

```bash
cp .env.example .env
# заполните DISCORD_TOKEN и CLIENT_ID
docker compose up -d --build
docker compose exec radio-bot npm run deploy-commands
```

Данные SQLite сохраняются в `./data` на хосте (volume), поэтому переживают
пересоздание контейнера.

⚠️ `@discordjs/opus` и `@snazzah/davey` — нативные модули. Готовые бинарники
есть не для всех сочетаний Node/glibc/архитектур, поэтому Dockerfile ставит
полный тулчейн сборки (`python3`, `make`, `g++`, `pkg-config`, `libopus-dev`)
для `@discordjs/opus`; `@snazzah/davey` подтягивает нужный прекомпилированный
бинарник (`linux-x64-gnu` и т.д.) сам через `npm install`, отдельная сборка
не нужна.

## Быстрый старт (локально, без Docker)

```bash
cp .env.example .env
npm install
npm run deploy-commands
npm start
```

## Переменные окружения (`.env`)

| Переменная | Обязательна | Описание |
|---|---|---|
| `DISCORD_TOKEN` | да | Токен бота |
| `CLIENT_ID` | да | ID приложения (application/bot ID) |
| `GUILD_ID` | нет | Если задан — команды деплоятся мгновенно только на этот сервер (для разработки). Без него — глобально, до ~1 часа на распространение |
| `DB_PATH` | нет | Путь к SQLite (по умолчанию `./data/bot.sqlite`) |
| `DEFAULT_VOLUME` | нет | Громкость по умолчанию, 0–100 (по умолчанию 70) |
| `LOG_LEVEL` | нет | `info` (по умолчанию) или `debug` для полного voice-лога |

**После смены `GUILD_ID` или списка команд обязательно перезапустить
`npm run deploy-commands`** — иначе новые/изменённые команды не появятся
на нужном сервере.

## Права бота при добавлении на сервер

Administrator не нужен. Минимальный набор:

- **Основные:** Просматривать каналы
- **Текстовые:** Отправлять сообщения, Встраивать ссылки, Использовать
  слэш-команды
- **Голосовые:** Подключаться, Говорить

Ссылка-приглашение с этим набором (замените `CLIENT_ID`):
```
https://discord.com/api/oauth2/authorize?client_id=CLIENT_ID&permissions=2150648832&scope=bot%20applications.commands
```

## Радиостанции

Единственное место, где задаются станции: `src/config/stations.yaml`.
У пользователей нет команды на добавление/изменение станций — только выбор
из этого списка через `/radio`.

```yaml
stations:
  - id: lofi-hiphop
    name: "Lofi hip hop radio"
    description: "Lofi beats to relax/study to"
    url: "https://play.streamafrica.net/lofiradio"
    icon: ""
```

⚠️ Публичные радио-потоки периодически меняют адрес или требуют
переопределения (например, у SomaFM бывают разные поддомены/суффиксы вида
`-128-mp3`). Перед добавлением новой станции проверьте URL вручную —
`ffplay <url>` или `curl -I <url>` должны отдать HTTP 200 и `audio/*`
content-type. Реальное название трека подхватится автоматически, если поток
отдаёт ICY-метаданные (заголовок `icy-metaint` в ответе) — это не
гарантировано для каждого стрима, но работает у всех станций, что сейчас
в конфиге.

```
├── commands/

│   ├── stop.js                  — /stop: пауза
│   ├── leave.js                 — /leave: выйти из канала
│   ├── radio.js                 — /radio: открыть Select Menu станций
│   ├── volume.js
│   ├── sleep.js                 — /sleep: таймер автовыхода
│   ├── 247.js                   — /247: режим 24/7
│   ├── dj-role.js                — /dj-role: назначить роль-контроллер
│   └── leaderboard.js           — /leaderboard: топ слушателей
├── interactions/
│   ├── radioSelectHandler.js    — обработка выбора станции
│   └── buttonHandler.js         — обработка кнопок приватной панели
├── audio/
│   ├── AudioManager.js          — реестр независимых сессий (per guild)
│   └── AudioSession.js          — голосовая сессия: connection, player, станция, громкость, пауза, реконнект, слип-таймер, трекинг прослушивания

├── config/
│   ├── env.js
│   └── stations.yaml            — единственный источник списка станций
└── utils/
    ├── djGuard.js                — проверка DJ-роли/ManageGuild
    ├── voiceGuards.js
    ├── embeds.js
    ├── controls.js               — кнопки панели + ссылки на Spotify/YouTube/Яндекс.Музыку
    ├── nowPlayingMessage.js      — приватная панель (ephemeral) + публичное объявление трека
    ├── attachSessionUI.js
    └── logger.js
```
